Yandex Link Router 1.0
======================

Ссылки на треки и альбомы Яндекс Музыки открываются сразу в приложении,
а не в браузере. Остальные ссылки — как обычно, в браузере.

Работает только на Windows 10 и 11.


Что это
-------
Маленькая программа-маршрутизатор (24 КБ). Она становится «браузером по умолчанию»
и смотрит, куда ведёт ссылка:

    music.yandex.ru/album/...   -> приложение Яндекс Музыки
    music.yandex.ru/track/...   -> приложение Яндекс Музыки
    music.yandex.ru/artist/...  -> приложение Яндекс Музыки
    плейлисты, профили          -> приложение Яндекс Музыки
    всё остальное               -> ваш браузер


Установка (1 минута, права администратора не нужны)
---------------------------------------------------
1. Запустить YandexLinkRouter-Setup.exe

   Если Windows покажет синее окно «Windows защитила ваш компьютер»:
   нажать «Подробнее» -> «Выполнить в любом случае».
   Это обычное предупреждение для новых программ без цифровой подписи.

2. Установщик откроет Параметры. Выбрать:

   Windows 10: Приложения -> Приложения по умолчанию -> Веб-браузер ->
               «Yandex Link Router»

   Windows 11: Приложения -> Приложения по умолчанию -> в поиске
               «Yandex Link Router» -> выбрать его для ссылок http и https

3. Проверить: кликнуть любую ссылку на трек Яндекс Музыки.


Что нужно
---------
- Windows 10 или 11.
- Установленное приложение «Яндекс Музыка» (обычная десктопная версия).
- Любой браузер: Firefox, Chrome, Edge, Opera, Vivaldi, Brave,
  Яндекс Браузер и т.п. Установщик сам запоминает браузер по умолчанию.

Если Яндекс Музыка не установлена — установщик предупредит, а ссылки
будут открываться в браузере, пока приложение не появится.


Важно: ссылки внутри браузера
-----------------------------
Маршрутизатор перехватывает ссылки, которые отдаёт система: из Telegram,
почты, проводника, ярлыков. Если кликнуть по ссылке НА СТРАНИЦЕ внутри
браузера, система в этом не участвует — такую ссылку маршрутизатор не увидит.

Для браузера такого способа нет: клик по ссылке внутри страницы не доходит
до Windows, поэтому маршрутизатор её не перехватывает. Такая ссылка просто
откроется в браузере — трек придётся найти в приложении вручную.
Если же ссылка пришла в мессенджер или другое приложение, открывайте её
оттуда: такие ссылки маршрутизатор перехватывает.


Если что-то не так
------------------
- Ссылки вообще перестали открываться: Параметры -> Приложения ->
  Приложения по умолчанию -> Веб-браузер -> выбрать свой браузер обратно.
- Журнал переходов: %LOCALAPPDATA%\YandexLinkRouter\router.log


Если сменили браузер
--------------------
Маршрутизатор запоминает браузер при установке и за настройками дальше
не следит. Выбрали другой браузер по умолчанию — обычные ссылки продолжат
уходить в старый.

Лечится повторным запуском установщика: он возьмёт актуальный браузер
(или сохранённый, если маршрутизатор всё ещё выбран), обновит настройки
и снова откроет Параметры. Заново выбирать «Yandex Link Router» не нужно,
если он уже выбран браузером.


Удаление
--------
1. Параметры -> Приложения -> Установленные приложения ->
   «Yandex Link Router» -> Удалить.
2. В открывшихся Параметрах выбрать браузер по умолчанию заново: запись
   о маршрутизаторе удалена, и Windows попросит выбрать, чем открывать ссылки.

Удаляются файлы из %LOCALAPPDATA%\Programs\YandexLinkRouter, ключи в реестре
и журнал %LOCALAPPDATA%\YandexLinkRouter.

Если удаление через Параметры недоступно, запустить деинсталлятор напрямую:

    %LOCALAPPDATA%\Programs\YandexLinkRouter\uninstall.exe /uninstall
